GEORGE MASON UNIVERSITY - OFFICIAL LOGO

File: gmu-logo.png (1080 x 324 pixels)
The full-color primary logo is included unmodified as an OPTIONAL asset.
The default template uses a newly typeset, two-line university name.
Enable the full official logo with:
  \stargmulogo{assets/institutions/gmu-logo.png}
Restore the text treatment with \stargmutext.

The optional official asset is separate from
STAR's custom midnight-blue/cyan identity. George Mason University owns
its university marks. This file is not part of the original STAR artwork.

Official asset URL:
https://www.gmu.edu/themes/custom/sf_mason_2024/logo.png
Official logo guide:
https://brand.gmu.edu/brand-guide/university-logos-and-marks

The original PNG bytes, aspect ratio, and colors are preserved.
When enabled, at the 40 pt maximum height the source exceeds 500 dpi.

Place a collaborating institution's PDF, PNG, or JPEG artwork in this
folder, then set \starpartner{Institution Name}{assets/institutions/file.pdf}
in the paper-info file. Leave the file argument empty for the placeholder,
or use \starhidepartner to remove that slot. Use approved monochrome
institution artwork through the optional arguments when available;
the class does not recolor third-party logos automatically.
