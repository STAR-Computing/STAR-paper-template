\begin{abstract}
System behavior emerges across software, model, compiler, and runtime
boundaries. This STAR Lab template supports papers that examine those
boundaries through an explicit threat model, an inspectable design, and
controlled evaluation. The two-column layout includes a full-width
architecture figure, compact tables, pseudocode, a code example, numeric
citations, and artifact guidance. The document is instructional sample
content, with no empirical security or performance claims. Replace every
example with the study's own design, evidence, and limitations.
\end{abstract}
